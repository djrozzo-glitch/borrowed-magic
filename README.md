# Взаймы / Borrowed Magic

Браузерная игра-прототип. Один файл `index.html`, без сборки и сервера: откройте его в браузере.

## Мир

**Фэнтези, но** магия никому не принадлежит. Её берут взаймы у мира: у реки, у огня, у памяти, у завтрашнего дня. Кредитор всегда взыскивает, и берёт не деньгами, а тем, чем владеет сам.

| Слой | Решение |
|---|---|
| Силы | Нужда (без чуда не выжить) и Долг (всё взятое возвращается) |
| Тип взаимодействия | Сделка. Не борьба: кредиторы не враги, они просто не прощают |
| Место взаимодействия | Между человеком и миром. Масштабируется от деревни до империй, заложенных морю |
| Давление | Проценты: долг растёт сам, а чистым никто не рождается |
| Тактические артефакты | Расписки: долг можно передать другому |
| Стратегический артефакт | Книга долгов: единственный экземпляр, в котором записано, кто кому должен. Тот, кто её перепишет, перепишет мир |

## Правила прототипа (v0.1)

- 20 дней, 8 жителей, 4 поля, 4 кредитора.
- Каждый день приходит беда с силой 1–4. Её можно перетерпеть (потерять жителей или поля) или снять заклинанием, заняв силу беды у одного кредитора.
- Одному кредитору беда «по части» (на 1 дешевле), другой может отказать.
- На рассвете каждый непогашенный долг растёт на 1.
- Если долг больше терпения кредитора, он забирает своё и терпение падает на 1 (минимум 2):
  - Река забирает поле.
  - Огонь забирает очаг вместе с жильцом.
  - Память забирает имя жителя (безымянные не работают) и стирает одну из цифр в Книге долгов.
  - Завтра забирает следующий день (беда ударит без вас) и прогноз.
- Жители с именами работают: каждые четверо дают 1 труд в день, труд гасит долг.
- Поле кормит троих. Лишние уходят по одному в день.
- После 20-го дня наступает День Расчёта: за каждое «терпение» остатка долга кредитор забирает ещё одну вещь.
- Счёт: сколько жителей помнят своё имя.

«Расклад дня» одинаков у всех, кто играет в этот день.

## Баланс

`tools/sim.js` прогоняет ботов по 2000 раскладов: `node tools/sim.js index.html`.

| Бот | Средний счёт | Проигрыш |
|---|---|---|
| Всегда терпит | 0 | 100% |
| Случайный | 0,2 | 88% |
| Занимает у одного кредитора | 2,8 | 26% |
| Жадный с расчётом на утро | 4,8 | 0% |

Идеальный результат (8 из 8) у лучшего бота выходит в 4% раскладов.
